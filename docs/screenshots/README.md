## Recapture checklist

Use a viewport near **1400×900** for consistent README rendering.

1. Start the local application or open the deployed demo.
2. Wait for each route to settle and confirm the serving-mode label is visible.
3. Capture the five routes above as full-page PNGs.
4. Replace the matching files in this directory.
5. Check that no screenshot implies dated snapshot output is current advice.

The SVG files are legacy placeholders and are not referenced by the README.
